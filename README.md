# 🚀 Aisha.dev | Portfolio

A high-performance, responsive portfolio website featuring a glassmorphism design. Built to showcase projects.

## 🌐 Live Demo
**[View Live Site](https://aishalight.github.io/portfolio/)**

---

## ✨ Key Features

* **Custom Particle Engine:** Interactive background using HTML5 Canvas.
* **Adaptive Glassmorphism:** A UI that transitions smoothly between high-contrast dark mode and clean frosted-glass light mode.
* **Command Palette:** (Ctrl+j) A terminal-style navigation overlay for power users.
* **Responsive Architecture:** Fully optimized for mobile, tablet, and ultra-wide desktops.
* **Secure Contact Form:** Integrated with FormSubmit for encrypted lead generation.

## 🛠️ Built With

* **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+)
* **Icons:** [BoxIcons](https://boxicons.com/)
* **Fonts:** Inter (via Google Fonts)
* **Animations:** Custom CSS Keyframes & Canvas API
